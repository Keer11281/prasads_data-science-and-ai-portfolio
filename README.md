# Data Science and AI Portfolio

This repository contains end-to-end data science and AI projects, including data analysis, feature engineering, machine learning models, and applied analytics, built with Python and focused on real-world use cases.

## Repository Structure

- 01-foundations  
  Core concepts: Python, NumPy, Pandas, data visualization, and EDA.

- 02-machine-learning  
  Supervised and unsupervised learning projects such as regression, classification, and clustering.

- 03-deep-learning  
  Neural networks, computer vision, and deep learning experiments.

- 04-ai-and-genai  
  AI systems, automation, agents, and generative AI projects (in progress).

## Goal

To build production-ready, interpretable, and business-focused data science and AI solutions.
